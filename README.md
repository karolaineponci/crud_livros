## 🚀 Passo a Passo para Rodar o Projeto

Como o projeto está dividido entre backend e frontend, siga as instruções abaixo para executar ambos utilizando o **Bun**:

### 1. Clonar o Repositório

No terminal da sua máquina, clone o projeto e acesse a pasta raiz:

```bash
git clone https://github.com/karolaineponci/crud_livros.git
cd crud_livros
```

### 2. Configurar e Rodar o Backend

Abra um terminal e navegue até a pasta do servidor (backend):

```bash
cd backend
```

Instale as dependências:

```bash
bun install
```

Inicie o servidor:

```bash
bun dev
```


### 3. Configurar e Rodar o Frontend

Abra um novo terminal (sem fechar o do backend) e navegue até a pasta da interface (frontend):

```bash
cd frontend
```

Instale as dependências:

```bash
bun install
```

Inicie a aplicação:

```bash
bun dev
```
